# Dostar Cinema — Midterm Project

An eight-page website about Dostar Cinema in Astana. The team used HTML, Bootstrap 5.3.3 and a small amount of CSS. The pages prepare forms and status areas for JavaScript work in later assignments. This version does not send feedback or reserve cinema seats.

## Three visitor journeys

1. **Find the cinema:** Start on Home - open Visit - read the location and route - open the map or phone link. End: the visitor has directions or a working contact method.
2. **Find a film and ticket:** Start on Home - open Movies - choose Schedule - open the current Ticketon listing - select an available session there. End: the visitor reaches a live ticket selection page with current prices.
3. **Check facilities and contact:** Start on Home - open Cinema - open Halls - open Services - open Visit - use the phone link. End: the visitor has checked the published hall and parking information and can contact the venue.

## Run

Open `index.html` in a browser with internet access. Bootstrap CSS and the existing Bootstrap navigation bundle load from jsDelivr. All eight pages are linked from the same menu.
