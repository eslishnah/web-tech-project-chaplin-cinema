# Dostar Cinema — Midterm Project

A seven-page website about Dostar Cinema in Astana. The team used HTML, Bootstrap 5.3.3 and a small amount of CSS. The pages prepare forms and status areas for JavaScript work in later assignments. This version does not send feedback or reserve cinema seats.

## Three visitor journeys

1. **Find the cinema:** Start on Home - open Visit - read the location and route - open the map or phone link. End: the visitor has directions or a working contact method.
2. **Order tickets on this site:** Start on Home - open Movies - continue to Schedule - follow the ticket order link - enter a session, date, ticket quantity and buyer details - inspect the order summary and confirmation area on the same page. The complete interface is present; updating the summary, calculating prices and confirming the order require JavaScript in a later assignment. The current HTML/CSS version does not issue tickets or take payment.
3. **Check facilities and contact:** Start on Home - open Cinema - open Halls - open Services - open Visit - use the phone link. End: the visitor has checked the published hall and parking information and can contact the venue.

## Run

Open `index.html` in a browser with internet access. Bootstrap CSS and the existing Bootstrap navigation bundle load from jsDelivr. All seven pages are linked from the same menu.
