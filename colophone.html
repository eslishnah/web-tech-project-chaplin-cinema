HTML structure

First we created simple HTML files. Every page has a header, navigation, main part and footer. We used semantic tags because they show the meaning of the page parts. We used section for a topic and article for a separate block of information.

We connect the pages with links like movies.html.

<main>
    <h1>Title</h1>
    <section>Content</section>
</main>

We press Ctrl + S to save. Then we open the page in the browser. A simple result is Page opened correctly.

Team process

Each student works on two pages. We check links, forms, headings and image names. After that we make Git commits.
