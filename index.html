About our project

Our project is about Chaplin Mega Silk Way cinema in Astana. We chose this place because it is real and we can visit it. The cinema is inside MEGA Silk Way. Our website has information about movies, halls, schedule, services and how to visit the cinema.

We are three students. Each student has two pages. We also have one home page and one colophon page. We use only HTML in this assignment. We do not use CSS or JavaScript now.
