About our project

Our project is about Dostar Cinema in Astana. The new design uses colours that we saw in the cinema: green for the main identity, orange for warm accents, dark panels for contrast and a light background for readable content.

This Assignment 2 version keeps the same HTML project structure and adds CSS selectors, Flexbox, Grid, positioning, spacing and typography. We still use local files and no JavaScript.
