# Bootstrap Migration

| Old CSS rule | Bootstrap replacement |
|---|---|
| Manual navigation Flexbox | navbar, navbar-expand-lg, navbar-nav |
| Manual page widths and margins | container, container-fluid |
| Manual CSS Grid galleries | row, col-12, col-md-6, col-lg-4, g-4 |
| Manual form Flexbox | row, col-*, form-control, form-select, form-check |
| Manual button styling | btn, btn-success, btn-outline-secondary |
| Manual table styling | table, table-striped, table-hover, table-responsive |
| Manual card styling | card, card-body, shadow-sm |
| Manual spacing rules | p-*, m-*, mb-*, py-*, gap-* |
| Hand-written responsive styles | Bootstrap responsive columns and display utilities |
| Float image layout | Bootstrap responsive rows and columns |
