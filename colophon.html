How We Made This Website

Our work

HTML and CSS structure

First we created the HTML pages and connected them with relative links. In Assignment 2 we added one shared base stylesheet and one personal stylesheet for each student's pages. The design is now based on Dostar Cinema.

For example, a content block can look like this:

<main>
    <h1 class="page-title">Dostar Cinema</h1>
    <section class="content-section">Content</section>
</main>

We press Ctrl + S to save changes. A successful result can be described as Page opened correctly.

Design process

The main green, warm orange, dark panels and light background are based on the Dostar Cinema photos used by our team.
