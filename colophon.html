How We Made This Website

Our work

HTML and Bootstrap structure

First we created the HTML pages and connected them with relative links. In the Bootstrap version we use containers, rows, columns, forms and utility classes.

For example, a content block can look like this:

<main class="container py-4">
  <h1 class="display-5">Dostar Cinema</h1>
  <section class="row g-4">Content</section>
</main>

We press Ctrl + S to save changes. A successful result is Page opened correctly.
